# Превью-страница геосервиса (`/preview`) — как устроена и как обновить медиа

Публичная страница «Что умеет геосервис»: `/preview` (то же — `/about`), ссылка «Что умеет геосервис» — на странице
входа. Без входа, без внешних библиотек и CDN: `index.html` + `preview.css` + `preview.js` (≈ 80 КБ), шрифт Inter из
`/static/fonts/`, медиа из `static/preview/media/`. Карта и «нырок» — **реальные данные**: космоснимок Esri World
Imagery и границы лесного фонда ГУ «Белгослес» (WFS: лесхозы, лесничества, кварталы, выделы). Пород на странице нет.

## Четыре сцены

1. **Окно под курсором** (первый экран). Два слоя одного кадра: сверху — «голый» снимок `hero-bare.webp`, снизу —
   живое видео `hero-alive.mp4`: тот же снимок, притемнённый, с границами — **лесхозы** (кремовые со свечением, только
   внешний контур), **лесничества** (бирюзовые), **кварталы** (янтарные, бегущий свет, номера), **выделы** (тонкие
   белые). Подписи: «ВИЛЕЙСКИЙ ОПЫТНЫЙ ЛЕСХОЗ» + лесничество второй строкой, номера кварталов — без наложений.
   Курсор прорезает в верхнем слое круглое окно (CSS `mask: radial-gradient(...)` по `--x/--y/--r`). Под курсором —
   подсказка **«Квартал 226 · выдел 11 / 0,5 га · Вилейское опытное лесничество / Вилейский опытный лесхоз»** и
   **подсветка выдела** (заливка + светящийся контур на `<canvas class="hl">` под верхним слоем, маска из
   `hero-ids.png`). Легенда — 4 типа границ с числом объектов в кадре (из `hero.json`).
2. **«Нырок» по скроллу** (620vh, 96 кадров + геоинтерполяция по `manifest.json`). Вся Беларусь с границами всех
   лесхозов → подсветка и название лесхоза участка → лесничества с названиями → кварталы с номерами → выделы.
   HUD: координаты, линейка, «М 1 : …». Подписи: «Вся Беларусь — на одной карте», «От страны — до своего лесхоза»,
   «Лесничества, кварталы, выделы», «Ваши планы — на своё место».
3. **Орбита** (`#orbit`, 340vh). Станция (МКС) над Землёй «пролетает» по прокрутке: 72 кадра `orbit/` на `<canvas>`,
   соседние кадры смешиваются (плавно и при 72 кадрах). У каждого кадра в `orbit/manifest.json` — рамка станции
   `hot`; по ней ставится «горячая» зона с маячком. **Наведение** (фокус с клавиатуры, касание) открывает панель
   «Сигнал со спутника · чем полезен геосервис»: 6 пунктов (меньше выездов, единые границы, минуты вместо часов, без
   установки ГИС, готово к отчёту, лес в 3D) — текст «печатается» один раз, от маячка к панели идёт луч. На
   телефоне кадр 16:9 показывается в 1,6 раза шире «contain», верх и низ растворяются в звёздном фоне; панель —
   нижний лист.
4. **Посадка** (`#landing`, 300vh). Космонавт подходит по прокрутке (72 кадра `astro/`, на телефоне — `astro-m/`
   9:16), к 82 % блока он на месте, и дальше «живёт» бесшовная петля `astro-loop.mp4` (стоит и машет; первый кадр
   петли = последний кадр подхода). **При наведении** на космонавта по сторонам фигуры «выезжают» кнопки: слева
   **ЗАРЕГИСТРИРОВАТЬСЯ** (`/?register=1` — карта откроет анкету гостя), справа **ВОЙТИ В ГЕОСЕРВИС ОДЗиМЛ** (`/`).
   Кнопки открываются и с клавиатуры (Tab), закрываются с задержкой и по Esc; на тач-экране — касанием или сами через
   ≈3 с после прибытия; на телефоне — внизу слева и справа. Сверху **летит спутник**: наведение — та же панель
   «чем полезен геосервис» рядом с ним (спутник замирает, пока панель открыта). Ссылка «Регистрация» в шапке
   прокручивает сразу к прибывшему космонавту.

`prefers-reduced-motion: reduce`: окно не бродит, видео не запускаются сами, кадры ставятся без доводки, текст не
печатается, спутник не летит, кнопки космонавта видны сразу.

## Файлы

| Файл | Назначение |
|---|---|
| `static/preview/index.html`, `preview.css`, `preview.js` | страница |
| `static/preview/media/` | медиа (генерируются, см. ниже) |
| `preview_page.py` | маршрут FastAPI: `GET /preview` и `/about`; версия `?v=<APP_VERSION>-<время hero.json>` во всех ссылках на `/static/preview/*`, абсолютный `og:image`, кэш готовой страницы |
| `templates/index.html` | `/?register=1`: гостю открывается анкета (`openProfileModal()`), параметр убирается из адреса |
| `nginx.conf` | `location ~* ^/static/preview/media/…\.(mp4|json)$` — диапазонные запросы видео, gzip для json |
| `tools/preview/make_preview_media.py`, `pvlib.py` | герой, «нырок», og.jpg — из снимков и WFS |
| `tools/preview/make_space_media.py` | орбита и посадка — из двух видео |

## Медиа и размеры (по умолчанию)

| Файл | Что это | Размер | Когда грузится |
|---|---|---|---|
| `hero-bare.webp` | «голый» снимок участка 1600×900 (верхний слой) | 396 КБ | сразу (preload) |
| `hero-alive.webp` / `.mp4` | тот же кадр с границами лесного фонда: постер и петля 6 с без звука | 376 КБ / 1,1 МБ | сразу; видео играет, пока окно открыто |
| `hero-ids.png` | карта выделов 800×450 (номер в R + G·256) — подсказка и подсветка | 52 КБ | после hero.json |
| `hero.json` | выделы `{id: [квартал, выдел, га, № лесничества, № лесхоза]}`, списки `lesnich`/`leshoz`, легенда 4 типов границ с `n`, `target` | 20 КБ | сразу |
| `frames/`, `frames-m/` | 96 кадров «нырка» 1280×720 / 720×1280 + manifest.json | 7,5 / 7,5 МБ | после load; телефон — `frames-m/` |
| `intro.mp4`, `intro-m.mp4` | интро-петля начала «нырка» | 356 / 340 КБ | при подходе к блоку |
| `orbit/` | 72 кадра станции 1280×720 + manifest.json (`hot` по кадрам) | 2,8 МБ | при подходе к блоку (за 1,5 экрана) |
| `astro/`, `astro-m/` | 72 кадра подхода космонавта 1280×720 / 540×960 + manifest.json (`hot`, `loop`, `loop_hot`, `loop_s`) | 3,2 / 2,2 МБ | при подходе; телефон — `astro-m/` |
| `astro-loop.mp4`, `astro-loop-m.mp4` | петля 9,3 с без звука, H.264, faststart | 0,6 / 0,7 МБ | на середине блока посадки |
| `og.jpg` | картинка ссылки 1200×630 | 236 КБ | только мессенджеры |

Первый экран — ≈ 0,9 МБ + видео героя; всё остальное догружается лениво при подходе к своему блоку.

## Как перегенерировать медиа

Нужны Python 3.9+, `numpy`, `pillow` (с WebP), `opencv-python-headless`, `ffmpeg` (libx264) в `PATH`, шрифт с
кириллицей (Linux — Noto Sans/Liberation/DejaVu, Windows — Segoe UI/Arial; свой — `PREVIEW_FONT=путь.ttf`).
```bash
cd geoservice
pip install numpy pillow opencv-python-headless
python3 tools/preview/make_preview_media.py --out static/preview/media                  # hero, story, og (~10 мин)
python3 tools/preview/make_preview_media.py --only hero,og --lat 53.42 --lon 28.63 --width 6000   # другой участок
python3 tools/preview/make_preview_media.py --only story --offline                      # только «нырок», из кэша
python3 tools/preview/make_space_media.py --orbit iss.mp4 --astro astronaut.mp4 --out static/preview/media
```
Ссылки на медиа обновятся сами: версия `?v=` строится из `APP_VERSION` и времени изменения `hero.json`, оба
генератора в конце обновляют это время.

Ключи `make_preview_media.py`:
* `--lat --lon --width` — центр участка и ширина кадра героя (м EPSG:3857); по умолчанию 54.4097, 26.7545 — река
  Вилия, граница Вилейского опытного и Молодечненского лесхозов (3 лесничества в кадре). Тот же участок — конец «нырка».
* `--wfs URL`; слои `--wfs-leshoz` (`BelGosLes:view_leshoz`), `--wfs-lesnich` (`BelGosLes:view_lesnich`),
  `--wfs-quarter` (`BelGosLes:quarter`), `--wfs-allot` (`BelGosLes:allotmentMin`); поля `--f-leshoz` (`name_lx`),
  `--f-lesnich` (`name_ln`), `--f-quarter` (`quarter_number`), `--f-allot` / `--f-allot-sub` / `--f-allot-quarter`
  (номер, подномер, квартал выдела), `--f-area` (`area`).
* `--timing k=v,...` — тайминги «нырка» (доли 0…1): `zoom0/1` приближение; `hl0…3`, `hn0…3` — подсветка и название
  лесхоза участка; `ln0/1`, `lt0…3` — лесничества и их названия; `q0/1`, `qt0/1` — кварталы и номера; `a0/1` — выделы;
  `dk0/1` — притемнение снимка.
* `--start-span`, `--start-shift-x/-y` — охват первого кадра (вся Беларусь); `--imagery URL{z}{x}{y}`, `--imagery-maxz`.
* `--frames`, `--frame-w/-h`, `--frame-mw/-mh`, `--portrait-scale`, `--q-frames`, `--q-hero`, `--soften`,
  `--crf-hero`, `--crf-intro`, `--alive-seconds`, `--intro-seconds`, `--label-px`, `--label-min`, `--qline`.
* `--cache DIR` (по умолчанию `~/.cache/geoservice-preview`), `--offline` — только из кэша.

Ключи `make_space_media.py`: `--orbit` и `--astro` — исходные видео (любой формат ffmpeg, звук отбрасывается);
`--orbit-frames`, `--orbit-from/--orbit-to` (с) — число кадров и отрезок орбиты; `--astro-frames`, `--astro-arrive`
(с, когда космонавт остановился); `--loop-min/--loop-max` — окно поиска длины петли (конец — кадр, больше всего
похожий на начало), `--xfade` — перекрёстный переход стыка; `--w/--h`, `--mw/--mh` — размеры; `--q` (WebP),
`--crf` (H.264), `--denoise` (по умолчанию `hqdn3d=1.5:1.5:3:3`); `--no-video` — только кадры.

## Атрибуция
Снимки — Esri World Imagery (Esri, Maxar, Earthstar Geographics); лесной фонд — ГУ «Белгослес»; контур страны —
Natural Earth (world-atlas). Подпись стоит в подвале страницы; при смене источников исправьте её в `index.html`.
