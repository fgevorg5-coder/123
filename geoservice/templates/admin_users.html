Бессрочный

Доступ ко всем слоям данных навсегда. Без ограничений по времени и скачиваниям.

Ограниченный по слоям

Доступ к определённым слоям (КС, БПЛА, Аэро, База) на ограниченное время.

На конкретный файл

Доступ к одному конкретному файлу из раздела съёмки. Ограничен по времени.

По количеству загрузок
